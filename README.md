# 🚗 Orion AutoWorks

**Orion AutoWorks** é um projeto acadêmico desenvolvido para a disciplina de **Projeto de Software**, com foco em **arquitetura de software, modelagem UML e documentação de sistemas**.

O objetivo é projetar uma plataforma para gerenciamento de oficinas mecânicas, permitindo o controle de clientes, veículos, ordens de serviço, orçamentos, estoque de peças e acompanhamento do fluxo de manutenção.

> **Importante:** Este repositório não contém a implementação do sistema. O escopo do projeto é exclusivamente a especificação, modelagem e documentação da solução.

---

## 🎯 Objetivos do Projeto

- Levantar requisitos funcionais e não funcionais;
- Definir regras de negócio do domínio;
- Modelar a arquitetura do sistema;
- Elaborar diagramas UML utilizando **PlantUML**;
- Projetar a estrutura de dados e os componentes da solução.

---

## 🏗️ Escopo do Sistema

O Orion AutoWorks tem como propósito digitalizar os principais processos de uma oficina mecânica, incluindo:

- Cadastro de clientes e veículos;
- Gerenciamento de ordens de serviço (OS);
- Elaboração e aprovação de orçamentos;
- Controle de estoque de peças;
- Acompanhamento do andamento dos serviços;
- Histórico de manutenção dos veículos;
- Controle de pagamentos e finalização dos atendimentos.
